Gmail Codex Bridge

Privacy Policy

Effective 22 October 2026. This policy describes Gmail Codex Bridge, a personal local utility operated by Roman Shostak for his own authorized Google account.

Information accessed and purpose

The bridge accesses Gmail conversation and message identifiers, sender and recipient information, subjects, dates, message bodies, labels, and supported attachments for conversations selected through its queue label. It uses this information to route conversations to the appropriate local project, translate and summarize new messages in Codex, and preserve continuity without repeatedly processing the same messages.

Permissions and changes

Google OAuth permission gmail.modify allows reading Gmail data and modifying labels and message markers. The bridge uses it to maintain queue and project labels and processing markers. It does not automatically send replies. It does not request or store the Google account password. OAuth access and refresh tokens are stored locally to authorize Gmail API requests.

Processing and sharing

Selected email content, relevant conversation context, and attachments when needed are made available to Codex / OpenAI to provide the requested analysis. Processing is subject to the applicable OpenAI account terms, data controls, and retention settings. The operator does not sell mailbox data, use it for advertising, or publish it on this website or in this repository. Google provides the Gmail API; GitHub hosts only these public informational pages. Mailbox data and OAuth tokens are not uploaded to GitHub by this website.

Storage and retention

The local computer stores OAuth tokens, processing identifiers, task mappings, operational logs, analysis reports, and downloaded attachments. Codex conversations also retain submitted content and results according to the account configuration. There is no fixed automatic deletion period for local reports, attachments, or task history; they remain until removed by the operator. Revoking Google access stops future authorized Gmail requests but does not delete previously stored local files or Codex conversations.

Control and deletion

The account owner can stop the local bridge, remove a conversation from its queue, or revoke the app connection in Google Account connections. Local bridge tokens, state, reports, and attachments can be removed on the computer. Codex conversation deletion and account data controls are managed separately in Codex / OpenAI. Removal from one location does not automatically remove copies from another.

This website

These two static informational pages contain no login, mailbox upload form, advertising, or analytics scripts. GitHub may process ordinary website access information under its own privacy statement.

Questions and updates

Contact the operator through the information repository. Never include email content, tokens, or other private information in public issues. Material changes to this policy will be reflected here with an updated effective date.
